# Частные дороги

Реестр частных (платных) дорог Государства 7Stars.

Порядок регистрации: Статья 21.4 Конституции, ЗК13.7stars. Налог: 40% от прибыли дороги (ЗК13.6.7stars). Государственный транспорт и экстренные службы проезжают бесплатно. Все дороги, не внесённые в этот реестр, государственные.

---

## Зарегистрированные частные дороги

Пока нет.
