# Граждане — Реестр граждан Государства 7Stars

Перечень граждан с указанием принадлежащего имущества и статуса.

Порядок приобретения гражданства: Статья 9.2 Конституции, ЗК14.7stars. Игрок лично обращается к Регистратору (здание Президента, ул. Центральная, 1, вход со стороны Проспекта Победы) и подаёт заявление. Запись вносится в течение **30 минут** (предельный срок), бесплатно. Без гражданства нельзя получать государственные услуги, обращаться в суд, регистрировать имущество и открывать ЧАО (ЗК14.7stars).
