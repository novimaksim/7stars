# Внешние постройки — Реестр внешних построек и схем

Ведение данного реестра осуществляется в соответствии с **ЗК10.7stars**.

Реестр учитывает все постройки, схемы и архитектурные элементы, созданные третьими лицами и используемые на территории Государства 7Stars (как с разрешением автора, так и без него / в рамках ГФНА).

---

## Порядок внесения записи

1. Подаётся заявление / принимается постановление / выносится решение суда.
2. Регистратор вносит запись в данный файл (или создаёт отдельный файл при необходимости).
3. Запись должна содержать все обязательные поля, указанные в ЗК10.4.7stars.
